# Changelog

## 1.8.0 - 2026-08-10

### Added

- Added four-viewport layout validation for wide, standard, medium and narrow windows.
- Added interaction checks for real navigation buttons, attachment tabs, side-panel controls and sidebar states.
- Added explicit quality constraints for dimensions, responsive behavior, secondary controls and native hit testing.
- Added a repository showcase image for the QQ2007 theme.

### Improved

- Stabilized the composer, attachments and image storage layout across theme changes.
- Kept the five global navigation buttons fixed before and after sidebar changes.
- Restored activity view separation, message navigation and native secondary panels.
- Unified toolbar controls with blue gradients, inner borders, shadows and visible hover/open states.
- Improved collapsed sidebar hover preview, summary panels, attachment tabs and file viewer controls.

### Fixed

- Fixed overlays, white gaps, incomplete borders and mismatched control heights.
- Fixed native attachment tabs and actions being hidden behind the themed header slot.
- Fixed active tabs being covered by the add button in constrained panels.
- Fixed missing sidebar collapse controls and non-responsive temporary-sidebar hover states.
- Removed a stray decorative dot from the native mode selector.
